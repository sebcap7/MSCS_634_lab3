# MSCS 634 Lab 3: Clustering Analysis Using K-Means and K-Medoids

## Purpose

The goal of this lab was to use clustering techniques on the Wine dataset from sklearn. I applied both K-Means and K-Medoids clustering and compared their results using performance metrics and visualizations.

---

## Dataset Information

The Wine dataset contains:

- 178 wine samples
- 13 numerical features
- 3 wine classes

Class distribution:

- Class 0: 59 samples
- Class 1: 71 samples
